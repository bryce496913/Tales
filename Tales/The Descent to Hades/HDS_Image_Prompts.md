# How to Use

1. Start a new image-generation chat and paste the **Style Block** and **Character Sheet** once, with the line: *“Use this style and these character designs for every image I ask for in this chat. Reply ‘ready’.”*
2. Then paste one prompt at a time (`HDS000`, `HDS001`, …). Each prompt also ends with a short style reminder, so it still works on its own in a fresh chat.
3. When a recurring character first looks right (Theo in `HDS002`, Hermes in `HDS002`, Persephone in `HDS013`, Hades in `HDS040`), attach that image as a reference for that character's later pages.
4. Export each image as a **square PNG, 1254 × 1254** (same as the Anubis art), named exactly as the heading, e.g. `HDS007.png`. Put them in `Tales/The Descent to Hades/Images/`.

# Style Block

> Square 1:1 storybook illustration for a mobile choose-your-own-adventure game. Clean modern cartoon style with confident dark outlines, smooth soft-gradient shading, subtle paper grain, rich atmospheric lighting and a clear focal point. Ancient Greek underworld setting. **First-person point of view: the camera is the player's eyes. The player is never shown, except the player's own hands or forearms at the bottom edge when a prompt says so.** No text, letters, captions, logos, borders or watermarks in the image. Not gory: danger is shown by mood, shadow and pose, never blood or wounds (except where a prompt mentions small cuts). Palette for underworld scenes: midnight navy (#0B1220), deep violet shadow (#1C1630), burnished bronze (#C08A4A), marble white (#EDE8DF), Aegean blue (#3E6E9E), pomegranate red (#9E2B3A) and pale asphodel grey (#C9C3B0).

**Short style reminder** (already appended to each prompt below as *Style:*):
*Square storybook cartoon illustration, bold dark outlines, soft gradient shading, first-person view, player not visible, no text.*

## HDS000 — The Storm at Tainaron
